================================================================================
HOW IT WORKS (STEP BY STEP)
================================================================================

1. User clicks "Generate Test Cases" button
2. Frontend sends story summary + description
3. POST request to http://localhost:3000/api/manual-test-cases/generate
4. Backend creates intelligent prompt from story
5. Sends prompt to Google Gemini LLM API
6. Gemini generates comprehensive test cases
7. Backend parses JSON response
8. Returns structured test cases (positive, negative, edge)
9. Frontend displays test cases in UI
10. User reviews and uses test cases

TOTAL TIME: 2-5 seconds
AUTOMATION: 100%

================================================================================
TROUBLESHOOTING
================================================================================

BACKEND WON'T START:
  $ npm install
  $ npm start

CANNOT POST ERROR:
  - Check backend is running: npm start
  - Verify port 3000: lsof -i :3000
  - Try different port: edit .env PORT=5000

API KEY ERROR:
  - Check .env file has GEMINI_API_KEY
  - Verify key is valid
  - Restart backend after changing .env

CORS ERROR:
  - Backend might not be running
  - Check http://localhost:3000/health
  - Restart backend server

SLOW GENERATION:
  - Network latency
  - Check internet connection
  - Verify Gemini API status
  - Try again later

NO TEST CASES:
  - Story description might be too vague
  - Try with more detailed acceptance criteria
  - Check browser console for errors
