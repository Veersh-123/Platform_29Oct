# HTML Integration Snippet

Add these code snippets to your `Orchestrator-Platform.html` to enable the Generate Test Cases functionality.

## 1. Add Script Reference (Before Closing </body> Tag)

Find the closing `</body>` tag in your HTML and add this script reference right before it:

```html
<!-- Gemini Test Case Generator - AI-Powered Test Case Generation -->
<script src="test-case-generator-ui.js"></script>
```

**Location:** At the very end of the HTML file, just before `</body>`

## 2. Add Generate Button (In Test Design Header)

Find this section in your HTML (around line 1400-1450):

```html
.testdesign-header { display: flex; align-items: flex-start; justify-content: space-between; gap: 16px; margin-bottom: 20px; padding-bottom: 16px; border-bottom: 1px solid #1a2f4a; }
```

Then find the test design issue header section:

```html
<div class="testdesign-header">
    <div>
        <div class="testdesign-issue-key" id="testDesignIssueKey"></div>
        <div class="testdesign-issue-summary" id="testDesignIssueSummary"></div>
        <div class="testdesign-issue-meta" id="testDesignIssueMeta"></div>
    </div>
    <!-- ADD THE BUTTON HERE -->
</div>
```

Replace that section with:

```html
<div class="testdesign-header">
    <div>
        <div class="testdesign-issue-key" id="testDesignIssueKey"></div>
        <div class="testdesign-issue-summary" id="testDesignIssueSummary"></div>
        <div class="testdesign-issue-meta" id="testDesignIssueMeta"></div>
    </div>
    <button id="generateTestCasesBtn" class="generate-btn">
        <span style="margin-right: 4px;">✨</span>Generate Test Cases
    </button>
</div>
```

## 3. Add Test Cases Container (In Test Design Panel)

Find this section in the HTML:

```html
.testdesign-panel { flex: 1; overflow-y: auto; padding: 24px 28px; }
```

And locate where test cases should be displayed (after the acceptance criteria box). Add this container:

```html
<!-- Test Cases Container - Generated by Gemini LLM -->
<div id="testCasesContainer" style="margin-top: 30px;">
    <!-- Generated test cases will be rendered here dynamically -->
</div>
```

## Step-by-Step Integration

1. **Open** `Orchestrator-Platform.html` in your editor
2. **Locate** the closing `</body>` tag
3. **Add** the script reference (Step 1)
4. **Find** the test design header section
5. **Add** the Generate Test Cases button (Step 2)
6. **Find** the test design panel
7. **Add** the test cases container (Step 3)
8. **(Optional)** Add CSS styling
9. **Save** the file
10. **Load** the HTML in your browser
11. **Start** the backend server (`npm start`)
12. **Test** by selecting a story and clicking the Generate button

## Troubleshooting Integration

### Button not appearing
- Check that the HTML snippet is correctly placed
- Verify script tag is loading `test-case-generator-ui.js`
- Check browser console for JavaScript errors

### Button not working
- Ensure backend server is running (`npm start`)
- Check that `apiBaseUrl` in the UI matches server URL
- Verify Gemini API key is configured in `.env`

### Test cases not displaying
- Check browser console for errors
- Verify API response in Network tab
- Ensure `.env` file has valid Gemini API key
