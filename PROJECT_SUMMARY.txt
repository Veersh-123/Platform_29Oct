SOLUTION OVERVIEW
================================================================================

A complete, enterprise-grade system for generating comprehensive test cases
using Google's Gemini LLM. The solution integrates seamlessly with your
Orchestrator Platform and Jira instance.

KEY CAPABILITIES:
✓ Intelligent test case generation from acceptance criteria
✓ Automatic positive, negative, and boundary scenario creation
✓ Context-aware test data and step sequencing
✓ Multiple export formats (JSON, Markdown, CSV)
✓ Beautiful UI with scenario grouping and statistics
✓ Production-ready backend with full error handling
✓ Comprehensive documentation and deployment guides

QUICK START (15 MINUTES)
================================================================================

STEP 1: Install Backend
  npm install @google/generative-ai express cors dotenv

STEP 2: Configure API Key
  - Get key from https://ai.google.dev/
  - Add to .env: GEMINI_API_KEY=your_key

STEP 3: Start Server
  npm start

STEP 4: Update HTML (3 changes)
  - Add script tag: <script src="test-case-generator-ui.js"></script>
  - Add button: <button id="generateTestCasesBtn" class="generate-btn">
  - Add container: <div id="testCasesContainer"></div>

STEP 5: Test It
  - Select a Jira story
  - Click "Generate Test Cases"
  - Review and export

TOTAL TIME: ~15 minutes

================================================================================
KEY API ENDPOINTS
================================================================================

POST /api/test-cases/generate
  Description: Generate test cases from acceptance criteria
  Input: storyId, storyTitle, acceptanceCriteria, description
  Output: Test cases with positive/negative/boundary scenarios
  Time: 2-5 seconds

POST /api/test-cases/validate
  Description: Validate generated test cases
  Input: Array of test cases
  Output: Validation results with errors

POST /api/test-cases/format
  Description: Export test cases in various formats
  Input: Test cases, format (json/markdown/csv)
  Output: Formatted content

GET /api/test-case-generator/verify
  Description: Verify Gemini configuration
  Output: Setup status and model info

GET /health
  Description: Health check endpoint
  Output: Server status

TROUBLESHOOTING QUICK REFERENCE
================================================================================

PROBLEM: "GEMINI_API_KEY is not configured"
SOLUTION: 
  1. Get key from https://ai.google.dev/
  2. Add to .env: GEMINI_API_KEY=your_key
  3. Restart server

PROBLEM: "Cannot GET /..."
SOLUTION:
  1. Ensure backend is running: npm start
  2. Check server is on port 3000
  3. Verify .js files are in project root

PROBLEM: Button not appearing
SOLUTION:
  1. Verify HTML script tag added
  2. Check browser console (F12)
  3. Reload page (Ctrl+F5)

PROBLEM: "Failed to generate test cases"
SOLUTION:
  1. Verify API key is valid
  2. Check acceptance criteria is descriptive
  3. Review server logs

PROBLEM: Slow generation
SOLUTION:
  1. Check Gemini API status
  2. Verify network connection
  3. Monitor server resources

For more help:
  - See INTEGRATION_GUIDE.md → Troubleshooting
  - Check server logs: npm start output
  - Review browser console: F12 → Console
